## Files

- `key_metrics.csv`: compact policy-level metrics including bucket-size >=3 share.
- `results_by_workload_load_policy_scale.csv`: aggregate policy x workload x load x scale table.
- `frontier_table.csv`: aggregate frontier table generated by the existing summarizer.
- `frontier_by_threshold.csv`: best throughput under configured miss-rate thresholds.
- `current_vs_slo_no_preemption_adaptive_guarded.csv`: relative deltas against `current`.
- `miss_by_shape.csv`: shape-level miss rate and latency.
- `bucket_size_distribution.csv`: denoise bucket size counts from raw profiles.
- `stagepool_replica_distribution.csv`: selected replica counts from StagePool profiles.
- `figures/*.svg`: compact visualizations for miss rate, goodput, throughput, P95 latency, and mean bucket size.
- `omitted_artifacts_manifest.csv`: raw/runtime artifacts intentionally left out of this package.

No JSON, JSONL, raw trace/profile, log, status, per-run `benchmark_result`, or large runtime artifact is included in this package.
